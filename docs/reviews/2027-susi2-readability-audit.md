# 2027 수시2차 입시 사이트 가독성·UI 코드 검토 — 2026-11-02

## 검토 범위 및 한계
- 저장소: `Hyeopgeon-Lee/k-bigdata-ipsi`, main 기준으로 시작한 개선 브랜치.
- 페이지: 메인, 입시안내, 학과안내, FAQ, 학과찾기, 모바일/데스크톱 공통 스타일.
- 방식: WCAG 2.2 텍스트 대비 계산 및 HTML/CSS/JS 정적 점검. **실제 배포 화면의 스크린샷, 브라우저 뷰포트/스크린리더/실기기 조작 검증은 수행하지 못함.**
- 기준: [W3C WCAG 2.2 SC 1.4.3](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html) 일반 텍스트 대비 4.5:1, 큰 글씨 3:1.
