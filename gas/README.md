# Google Apps Script Public Read API

1. 스키마 문서대로 Google Spreadsheet에 13개 시트를 만듭니다.
2. 이 폴더의 코드를 Spreadsheet에 연결된 Apps Script 프로젝트에 복사합니다.
3. 웹 앱으로 배포하고 실행 계정은 본인, 접근 권한은 모든 사용자로 설정합니다.
4. 배포 URL을 `assets/js/common.js`의 `API_ENDPOINT`에 입력합니다.

지원 resource: bootstrap, config, departments, compare, admission, results, outcomes, media, faq, finder, testimonials, links, department, health. 개인정보나 비밀키를 시트에 저장하지 마세요.
